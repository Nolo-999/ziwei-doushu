## 断命总纲 / Reading Principles

1. **看命宫**：吉凶、庙旺、化吉化忌、生克。命无正曜者，看财帛、官禄二宫有吉拱照。
2. **看身主**：吉凶生克（身宫定根基）。
3. **看迁移、财帛、官禄**：三方四正的刑冲克破。
4. **看福德宫**：权禄劫空庙陷——定人心性与晚福。
5. **断盘次序，破限优先**：先查破限之象（官司牢狱、偏门、赌运、毒瘾、桃花外遇、短命横死、克夫克妻、无后、妖邪、背刺、心魔、绝境、自作孽），有则优先讲透；基础断语靠后。
